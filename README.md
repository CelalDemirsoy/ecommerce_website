> A fully functional, production-grade e-commerce platform — live at [glories.online](https://www.glories.online)

## ✨ Features

- 🏠 **Home Page** — Hero banner, featured products, category navigation
- 📦 **Products Page** — Full catalog with category filtering and search
- 🔍 **Product Detail** — Images, pricing, ratings, quantity selector
- 🛒 **Shopping Cart** — Add, remove, update quantities
- 💳 **Checkout** — Complete checkout flow
- 📱 **Responsive Design** — Mobile & desktop
- 📬 **Contact Page** — Business contact form

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| Next.js 14 | Framework |
| React 18 | UI |
| Tailwind CSS | Styling |
| Radix UI | Components |
| Lucide Icons | Icons |
| State: React Context API | Cart & state management |

## 🚀 Getting Started

```bash
git clone https://github.com/CelalDemirsoy/ecommerce_website.git
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
